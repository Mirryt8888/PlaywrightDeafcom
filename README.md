# PlaywrightDeafcom – Automatizované E2E testy

Ukázkový projekt automatizovaného testování webové aplikace **Deafcom** (`https://app.deafcom.cz/login`) pomocí frameworku **Playwright** v jazyce JavaScript.

## Co testy ověřují
* **TC-01:** Kontrola viditelnosti a dostupnosti klíčových prvků přihlašovacího formuláře (pole pro e-mail, heslo a tlačítko pro odeslání).
* **TC-02:** Ověření chování aplikace při pokusu o přihlášení s neplatnými údaji.

## Použité technologie
* **Playwright** (`@playwright/test`)
* **JavaScript** (Node.js)
* **GitHub Actions** (CI/CD konfigurace pro automatické spouštění testů)
